# Customer Requirements

**Primary customer:** Library Administrator / Librarian  
**Secondary users:** Students, faculty and library staff.

| ID | Requirement | Measurable Acceptance |
|---|---|---|
| CR-01 | Manage books | Valid book record is saved and listed immediately |
| CR-02 | Search catalog | Search returns matching ISBN/title/author/category records |
| CR-03 | Manage members | Valid member record is saved and searchable |
| CR-04 | Issue books | Unavailable books are prevented from issue |
| CR-05 | Return books | Active transaction is changed to RETURNED and inventory is restored |
| CR-06 | Prevent input errors | Required fields and numeric/email fields are validated before persistence |
| CR-07 | Traceability | Important actions create timestamped audit records |
| CR-08 | Maintainability | Core functionality is separated into modules and configuration files |
