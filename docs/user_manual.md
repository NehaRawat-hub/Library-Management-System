# User Manual

1. Run `python main.py`.
2. Default demo accounts: `admin/admin123` and `staff/staff123`.
3. Use Books to search/add/delete catalog records.
4. Use Members to manage library members.
5. Use Issue / Return to transact books.
6. Use Quality Monitor to view actual quality metrics.
7. Use Audit Logs to inspect traceability.

For production deployment, change demo credentials and add stronger authentication.
