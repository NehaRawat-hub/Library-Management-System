# Software Requirements Specification — Library Management System

## 1. Purpose
Provide a local GUI system for managing library books, members and issue/return transactions.

## 2. Scope
Book CRUD, member CRUD, catalog search, issue/return, authentication, activity/audit logging, error handling and quality monitoring.

## 3. Functional Requirements
FR-01 Login; FR-02 Book CRUD; FR-03 Member CRUD; FR-04 Search; FR-05 Issue; FR-06 Return; FR-07 Audit logging; FR-08 Error logging; FR-09 Quality monitoring.

## 4. Non-Functional Requirements
Usability, reliability, maintainability, data integrity, traceability and responsive local operation.

## 5. Quality Requirements
Input validation, database constraints, centralized exception handling, modular design and measurable quality evidence.
